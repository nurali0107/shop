# ShopKZ - Интернет-магазин

Қазақстандағы ең ыңғайлы интернет-дүкен. Смартфондар, ноутбуктер, электроника және басқа да өнімдер.

## SEO Оптимизация

Сайт іздеу жүйелерінде оңай табылуы үшін келесі SEO оптимизациялар қосылған:

### 1. Мета-тегтер
- Title, Description, Keywords
- Open Graph тегтері (Facebook, VK)
- Twitter Card тегтері
- Geo-локация тегтері (Қазақстан)
- Hreflang тегтері (қазақ және орыс тілдері)

### 2. Структурированные данные (Schema.org)
- Store schema
- Product schema
- Breadcrumb schema
- Organization schema

### 3. Технические файлы
- `robots.txt` - іздеу жүйелеріне нұсқаулар
- `sitemap.xml` - сайт картасы
- `.htaccess` - сервер конфигурациясы

### 4. Оптимизация для Казахстана
- Yandex верификация
- Google верификация
- Geo-тегтер (KZ)
- Локализация контента

## Использование

1. Откройте `index.html` в браузере
2. Для управления товарами перейдите в `admin.html`
3. Все данные сохраняются в localStorage браузера

## Настройка SEO

### Yandex Webmaster
1. Зарегистрируйтесь в [Yandex Webmaster](https://webmaster.yandex.ru/)
2. Добавьте мета-тег верификации в `index.html`:
```html
<meta name="yandex-verification" content="ВАШ_КОД">
```

### Google Search Console
1. Зарегистрируйтесь в [Google Search Console](https://search.google.com/search-console)
2. Добавьте мета-тег верификации в `index.html`:
```html
<meta name="google-site-verification" content="ВАШ_КОД">
```

### Обновление URL
Замените `https://shopkz.kz/` на ваш реальный домен во всех файлах:
- `index.html` (meta теги)
- `sitemap.xml`
- `.htaccess`
- `robots.txt`
