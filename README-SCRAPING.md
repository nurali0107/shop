# 🚀 Агрессивный скрапинг Nike и Adidas

## Метод 1: Браузерная консоль (РЕКОМЕНДУЕТСЯ - обходит CORS)

Этот метод работает напрямую на сайте Nike/Adidas и обходит все CORS ограничения.

### Инструкция:

1. **Откройте сайт:**
   - Nike: https://www.nike.com
   - Adidas: https://www.adidas.com/kz/

2. **Откройте консоль браузера:**
   - Нажмите `F12` или `Ctrl+Shift+I` (Windows) / `Cmd+Option+I` (Mac)
   - Перейдите на вкладку "Console"

3. **Запустите скрипт:**
   - Откройте файл `scrape-nike-adidas-console.js`
   - Скопируйте весь код
   - Вставьте в консоль браузера
   - Нажмите `Enter`

4. **Скрипт автоматически:**
   - Прокрутит страницу для загрузки всех товаров
   - Соберет все данные (название, цена, фото, категория, размер, модель)
   - Сохранит в localStorage
   - Скачает JSON файл

5. **Импорт в админ панель:**
   - Откройте админ панель вашего сайта
   - Нажмите "Импорттау"
   - Выберите "localStorage (Браузер консольінен)"
   - Нажмите "📥 Импорттау localStorage-тан"
   - Товары будут автоматически добавлены!

### Преимущества:
- ✅ Обходит все CORS ограничения
- ✅ Работает напрямую на сайте
- ✅ Собирает максимум данных
- ✅ Автоматически определяет категории
- ✅ Переводит цены в тенге с наценкой 10%

## Метод 2: Автоматический через админ панель

Если CORS не блокирует, можно использовать кнопки в админ панели:

1. Откройте админ панель
2. Нажмите "✅ Nike тауарларын қосу" или "✅ Adidas тауарларын қосу"
3. Дождитесь завершения процесса

**Примечание:** Этот метод может не работать из-за CORS ограничений браузера.

## Что собирается:

- ✅ Название товара (переведенное на русский)
- ✅ Цена (конвертированная в тенге + 10% наценка)
- ✅ Фото (полный URL)
- ✅ Категория (sneakers, shirts, pants, jackets)
- ✅ Пол (women/men)
- ✅ Размер (если доступен)
- ✅ Модель (из названия)

## Устранение проблем:

### "CORS шектеулері" ошибка
**Решение:** Используйте Метод 1 (браузерная консоль)

### "Тауарлар табылмады"
**Решение:** 
- Убедитесь, что вы на странице с товарами (не на главной)
- Попробуйте открыть конкретную категорию (например, "Мужские кроссовки")
- Обновите страницу и попробуйте снова

### "Баға табылмады"
**Решение:**
- Скрипт автоматически ищет цены в разных местах
- Если цена не найдена, товар будет пропущен
- Это нормально - не все элементы на странице являются товарами
